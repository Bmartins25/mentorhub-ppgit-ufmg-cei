# MentorHub — PPGIT/UFMG/CEI

MVP demonstrativo com dados fictícios e ranking experimental de mentores.

## Publicação no Streamlit Community Cloud

1. Crie um repositório GitHub e envie os arquivos desta pasta **na raiz** (incluindo `.streamlit/config.toml`).
2. Entre em https://share.streamlit.io/ e selecione **Create app** > **Deploy a public app from GitHub**.
3. Selecione o repositório, a branch `main` e o arquivo `app.py`.
4. Clique em **Deploy**.

O arquivo `requirements.txt` instala somente o Streamlit. O modo de IA semântica com Sentence Transformers requer dependências extras e não está habilitado nesta publicação leve; utilize o modo **Textual leve**.

**Atenção:** não envie informações pessoais reais para o demonstrativo público.
